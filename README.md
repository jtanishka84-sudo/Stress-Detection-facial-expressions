# Stress Level Detection from Facial Expressions
## About the Project
Build a CLIP-based deep learning model that predicts stress scores from facial images.Takes random images from the dataset and outputs a predicted stress level
## Dataset
- Source:Kaggle - https://www.kaggle.com/datasets/janithukwattage/stress-faces-dataset
- Size: ~12000 images
- Classes stress levels(e.g. stress/nostress)
## Tech Stack
- Python, PyTorch, CLIP, NumPy, Matplotlib
- Google Colab
## Model
- Architecture: Contrastive Language-Image Pretraining (CLIP)
- Validation Accuracy:72%
- Preprocessing: Grayscale, resize to 48x48, normalisation
